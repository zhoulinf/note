1计算机系统长什么样？

很多人一听到"计算机组成原理"就觉得是硬件课，其实它讲的是硬件和软件如何配合，让一台机器真正"跑起来"。

一台计算机系统 = 硬件 + 软件。二者缺一不可：没有软件的硬件只是一堆废铁，没有硬件的软件只是纸上谈兵。

一句话理解：硬件是"身体"，软件是"灵魂"。本教程主要讲硬件这一层是怎么组织和工作的。

2冯·诺依曼体系结构：计算机的"总图纸"

1945 年，数学家冯·诺依曼提出了一个至今仍在使用的计算机结构思想，核心只有两条：

  1. 存储程序：程序和数据一样，都以二进制形式存放在存储器里。
  2. 顺序执行：CPU 按顺序一条一条地取出指令、执行指令。

整个计算机被划分为五大部件，它们通过总线互相连接：

五大部件各干什么？

部件作用打个比方
运算器完成算术运算（加减乘除）和逻辑运算（与或非）工厂里的加工车间
控制器取指令、分析指令、发出控制信号，协调各部件工厂里的调度中心
存储器存放程序和数据，按地址读写仓库
输入设备把外界信息变成计算机能识别的二进制进货口
输出设备把计算结果变成人类能看懂的形式出货口
划重点：现代计算机把运算器 + 控制器 + 寄存器组集成在一块芯片上，统称为 CPU。所以"五大部件"实际常被说成"CPU + 存储器 + 输入设备 + 输出设备"。
想一想：为什么程序要和数据放在一起？

如果把程序写死在电路里（像早期的插线板计算机），换一个任务就要重新接线，非常麻烦。把程序当成"数据"存进内存后，只要换一段程序，同一台机器就能干完全不同的事——这就是现代计算机"通用性"的来源。

3CPU：计算机的"大脑"

CPU（Central Processing Unit，中央处理器）是整台机器的核心，它由三大部分组成：

控制器（CU）：指挥官

  • 从内存取出指令
  • 分析这条指令要干什么（译码）
  • 向运算器、存储器、IO 发出相应的控制信号

运算器（ALU）：干活的手

  • 算术运算：加、减、乘、除
  • 逻辑运算：与、或、非、异或、移位、比较
  • 本身很"笨"，只会算，全靠控制器指挥

寄存器：CPU 的"手掌心"

寄存器是 CPU 内部速度最快、容量最小的存储单元。几个常见角色：

名称英文作用
PCProgram Counter存放下一条要执行指令的地址，每执行一条自动 +1
IRInstruction Register存放当前正在执行的那条指令
MARMemory Address Register存放要访问的内存地址
MDRMemory Data Register存放从内存读出或要写入内存的数据
PSWProgram Status Word存放运算结果的状态（进位、溢出、零标志等）
形象比喻：把 CPU 想象成一个厨师。
控制器 = 大脑，决定下一步做什么菜；
运算器 = 双手，负责切菜炒菜；
寄存器 = 手边的调料碗，随手就能拿到；
Cache = 冰箱，取东西比去超市（内存）快得多。

4存储器：计算机的"记忆"

存储器不是一个东西，而是一个金字塔式的层次结构。越往上越快、越小、越贵；越往下越慢、越大、越便宜。

层次典型容量访问速度特点
寄存器几十 ~ 几百字节约 0.3 纳秒在 CPU 内部，最快
Cache几 MB ~ 几十 MB1 ~ 10 纳秒缓解 CPU 与内存的速度差
主存（内存）8 GB ~ 64 GB约 50 ~ 100 纳秒断电即失，程序运行时住这里
外存（SSD/硬盘）256 GB ~ 数 TB微秒 ~ 毫秒级断电不丢，长期存放

内存是怎么"找东西"的？

内存被划分成一个个存储单元，每个单元有一个唯一的地址，就像一条街上每户人家都有门牌号。

想一想：内存 8GB 和硬盘 512GB，为什么不都用内存？

因为内存（DRAM）速度快但成本高、断电就丢数据。硬盘便宜、容量大、断电不丢。计算机采用"金字塔"策略：用少量昂贵的内存保证速度，用大量便宜的硬盘保证容量，再用 Cache 把最常用的数据搬到 CPU 旁边，兼顾速度与成本。

5总线与输入输出：计算机的"血管"和"五官"

总线（Bus）：一根线，传三类信号

如果 CPU、内存、硬盘之间两两连线，线路数量会爆炸。所以计算机采用总线——一组公共的连线，所有部件都挂在上面，分时使用。

关键点：
数据总线的条数决定一次能搬多少位数据（32 位 / 64 位）；
地址总线的条数决定能寻址多大空间（n 条地址线 → 2ⁿ 个地址）。

输入 / 输出设备：计算机的"五官与手脚"

输入设备

键盘、鼠标、触摸屏、摄像头、麦克风、扫描仪
把现实世界的信息转换成二进制 0/1

输出设备

显示器、打印机、音箱、投影仪
把二进制结果还原成人能看懂的形式

外存设备

SSD、机械硬盘、U 盘、光盘
既是输入设备也是输出设备，可长期保存数据

接口 / 驱动

USB、HDMI、网口等接口 + 驱动程序
负责速度匹配与信号转换

6一条指令的一生：指令周期

CPU 的工作说白了就是不停地重复同一个循环：取指令 → 分析 → 执行。这个过程叫指令周期。

用一个具体例子走一遍

假设内存里存着这样一条指令：把内存 0010 号单元的数加到寄存器 R1 中。

  1. 取指令：PC 里存着 0100，CPU 用 MAR 把地址送出去，内存把该地址的指令内容通过 MDR 送回 IR，同时 PC 自动 +1。
  2. 译码：控制器一看，哦，这是一条"加法"指令，操作数在内存 0010 单元。
  3. 执行：控制器指挥 ALU 把 R1 里的值和取来的数相加。
  4. 访存：如果数据还在内存里，需要再去内存取一次。
  5. 写回：把结果写回 R1，同时更新 PSW 状态标志。

然后，重复下一轮。CPU 每秒可以重复几十亿次这样的循环。

记住这句：CPU 干的活 = 取指 → 译码 → 执行，无限循环，直到关机。

7数据在计算机里长什么样？

计算机里的一切——文字、图片、视频、程序——最终都变成 0 和 1。每一位叫一个 bit（比特），8 个 bit 组成一个 Byte（字节）。

二进制转十进制

以 10110010 为例，从右往左，每一位的权重是 2 的幂：

1 0 1 1 0 0 1 0
权重：128　64　32　16　8　4　2　1

1×128 + 0×64 + 1×32 + 1×16 + 0×8 + 0×4 + 1×2 + 0×1 = 178

原码、反码、补码：负数怎么表示？

正数好办，负数怎么办？人们想了很多办法。现代计算机统一使用补码。

数值原码反码补码
+50000 01010000 01010000 0101
-51000 01011111 10101111 1011
+00000 00000000 00000000 0000
-01000 00001111 11110000 0000

规则很简单：

  • 原码：最高位当符号位（0 正 1 负），其余位表示数值大小。
  • 反码：正数不变；负数符号位不变，其余位按位取反。
  • 补码：正数不变；负数 = 反码 + 1。
为什么用补码？因为用补码后，减法可以变成加法！比如算 5 − 3，直接算 5 + (−3) 的补码就行。这样 CPU 里只需要一个加法器，电路大大简化。
顺便，补码还解决了"+0 和 −0 两个零"的尴尬问题。
想一想：8 位补码能表示多大的范围？

n 位补码的范围是 −2ⁿ⁻¹ 到 2ⁿ⁻¹ − 1。8 位就是 −128 ~ +127。这也是为什么很多编程语言里 byte 类型的范围正好是 −128 到 127。

8怎么衡量一台计算机快不快？

主频

CPU 时钟频率，如 3.5 GHz，表示每秒 35 亿个时钟周期。频率越高，节奏越快。

CPI

Cycles Per Instruction，执行一条指令平均需要的时钟周期数。越小越好。

MIPS

每秒执行多少百万条指令，衡量运算速度的常用单位。

字长

CPU 一次能处理的二进制位数，如 64 位。字长越大，一次能算的数据越多。

存储容量

内存和硬盘能装多少数据，单位 GB / TB。

吞吐量

单位时间内系统能完成的任务总量，反映整体处理能力。

核心公式：
程序执行时间 = 指令条数 × CPI × 时钟周期
（指令条数由编译器和程序决定，CPI 由 CPU 结构决定，时钟周期由主频决定）

所以，评价一台计算机不能只看主频。同样 3.0 GHz，如果 A 的 CPI 是 2，B 的 CPI 是 4，那么 A 大概快一倍。

9知识总结：一张图记住全部

计算机系统 ├─ 硬件 │ ├─ 主机 │ │ ├─ CPU = 运算器(ALU) + 控制器(CU) + 寄存器组 + Cache │ │ └─ 主存（内存）：按地址存取，断电即失 │ └─ 外设 │ ├─ 输入设备：键盘 / 鼠标 / 摄像头 │ ├─ 输出设备：显示器 / 打印机 │ └─ 外存：SSD / 硬盘（断电不丢） │ ├─ 软件 │ ├─ 系统软件：操作系统 / 编译器 / 驱动 │ └─ 应用软件：浏览器 / 微信 / 游戏 │ └─ 连接纽带 ├─ 总线：数据总线 + 地址总线 + 控制总线 └─ 工作方式：取指 → 译码 → 执行（无限循环）

三个必须记住的核心结论

  1. 存储程序思想：程序和数据都放在内存里，用二进制表示，CPU 顺序取指执行。
  2. 层次化存储：寄存器 → Cache → 主存 → 外存，用"速度换成本"，越靠近 CPU 越快越小越贵。
  3. 总线连接一切：数据总线传数据、地址总线传地址、控制总线传命令，三者分工明确。

计性能指标计算高频

这是每年选择题的"送分题"，但公式必须记牢。

核心公式

CPU 执行时间 CPU 时间 = 指令条数 × CPI × 时钟周期 = 指令条数 × CPI ÷ 主频
MIPS（每秒百万条指令） MIPS = 主频 ÷ (CPI × 10⁶) 注意：主频单位是 Hz；若题目给 GHz，需换算成 10⁹ Hz
平均 CPI 平均 CPI = Σ(各类指令占比 × 该类 CPI) 占比用小数表示，不是百分数
例题 1
计算机 M 的主频为 2GHz，程序 P 包含 10⁸ 条指令，平均 CPI 为 1.5。求 CPU 执行时间和 MIPS。
  • CPU 执行时间 = 10⁸ × 1.5 ÷ (2 × 10⁹) = 0.075 秒 = 75 ms
  • MIPS = 2 × 10⁹ ÷ (1.5 × 10⁶) ≈ 1333
例题 2（指令混合）
某程序指令构成如下，求平均 CPI。
指令类型占比CPI
算术逻辑40%1
Load/Store30%2
分支20%3
其他10%4
平均 CPI = 0.4×1 + 0.3×2 + 0.2×3 + 0.1×4 = 0.4 + 0.6 + 0.6 + 0.4 = 2.0

计数据表示与运算计算必考

3.1 补码与原码的范围

编码8 位范围特点
原码−127 ~ +127两个零（+0 和 −0）
反码−127 ~ +127两个零
补码−128 ~ +127唯一零，减法变加法
移码−128 ~ +127用于浮点数阶码
n 位补码表示范围 −2ⁿ⁻¹ ~ 2ⁿ⁻¹ − 1

3.2 补码加减运算与溢出判断

规则：符号位与数值位一起参与运算，符号位产生的进位丢弃。

双符号位溢出判断 结果两位符号位相同 → 无溢出；不同（01 或 10）→ 溢出 01 表示正溢出（上溢），10 表示负溢出（下溢）
例题
用 8 位补码计算 (−95) + (−58)，判断是否溢出。
  • −95 补码：10100001
  • −58 补码：11000110
  • 相加：10100001 + 11000110 = 1 01100111，丢弃最高进位 → 01100111 = +103
  • 判断：两个负数相加结果为正数，溢出。实际结果应为 −153，超出 8 位补码范围（−128~+127）。

3.3 IEEE 754 浮点数★★★★★

单精度 32 位格式：

符号位 S阶码 E尾数 M
1 位8 位（偏移量 127）23 位

双精度 64 位：1 位符号 + 11 位阶码（偏移量 1023）+ 52 位尾数

IEEE 754 真值公式 V = (−1)^S × 1.M × 2^(E−127) 尾数隐含整数部分的"1."，这是 IEEE 754 的关键设计

类型 1：十进制 → IEEE 754

例题
将 37.25 转换为 IEEE 754 单精度格式。
  • 转二进制：37.25 = 100101.01
  • 规格化：1.0010101 × 2⁵
  • 符号位 S = 0（正数）
  • 阶码 E = 5 + 127 = 132 = 10000100
  • 尾数 M = 00101010000000000000000（去掉隐含的 1）
  • 结果：0 10000100 00101010000000000000000 = 42150000H

类型 2：IEEE 754 → 十进制

例题
某浮点数十六进制表示为 C6400000H，求其十进制值。
  • 转二进制：1100 0110 0100 0000 0000 0000 0000 0000
  • 拆分：S=1（负数），E=10001100=140，M=10000000000000000000000
  • 阶码真值 = 140 − 127 = 13
  • 尾数 = 1.1000...0（隐含 1 + M）
  • 真值 = −1.1₂ × 2¹³ = −(1 + 0.5) × 8192 = −12288

类型 3：浮点数加减运算

五步法（必须按顺序）：

  1. 对阶：小阶向大阶看齐，尾数右移（移动阶差位数）
  2. 尾数加减：按定点数规则运算
  3. 规格化：若尾数溢出则右规（右移 1 位，阶码 +1）；若尾数首位与符号位相同则左规
  4. 舍入：0 舍 1 入法或恒置 1 法
  5. 溢出判断：阶码是否超出范围
例题
x = 0.1101 × 2¹⁰，y = 0.1011 × 2⁰¹，阶码和尾数均为 4 位，求 x+y。
  • ① 对阶：阶差 = 10 − 01 = 1（十进制），x 阶码大，y 尾数右移 1 位：y 尾数变为 0.01011
  • ② 尾数相加：0.1101 + 0.01011 = 1.00101，溢出，需右规
  • ③ 右规：尾数右移 1 位 → 0.100101，阶码 +1 → 10+1 = 11
  • ④ 舍入（尾数 4 位）：0.1001 | 01，0 舍 1 入 → 0.1010
  • 结果：0.1010 × 2¹¹

计存储系统计算高频应用题

4.1 Cache 地址划分（核心中的核心）

主存地址根据映射方式拆分为不同字段：

映射方式地址划分
直接映射标记 + 行号 + 块内地址
全相联映射标记 + 块内地址
组相联映射标记 + 组号 + 块内地址
Cache 地址字段计算 块内地址位数 = log₂(块大小)
组号位数 = log₂(Cache 组数) = log₂(Cache 总块数 ÷ 每组块数)
标记位数 = 主存地址位数 − 组号位数 − 块内地址位数
例题
主存地址空间 64KB，Cache 数据区 4KB，块大小 32B，采用 4 路组相联。求主存地址各字段位数。
  • 主存地址：16 位（64KB = 2¹⁶）
  • 块内地址：log₂32 = 5 位
  • Cache 总块数 = 4KB ÷ 32B = 128 块
  • Cache 组数 = 128 ÷ 4 = 32 组
  • 组号：log₂32 = 5 位
  • 标记：16 − 5 − 5 = 6 位

地址字段可视化：

标记 6 位
组号 5 位
块内地址 5 位

4.2 Cache 命中率与平均访问时间

命中率 H = 命中次数 ÷ 总访问次数
平均访问时间（两种情形） 不并行：Ta = H × Tc + (1−H) × Tm
先访 Cache 再访主存（串行）：Ta = Tc + (1−H) × Tm Tc = Cache 访问时间，Tm = 主存访问时间
例题
程序访存 1000 次，未命中 50 次。Cache 访问时间 1ns，主存访问时间 50ns（缺失时先访 Cache 再访主存）。求平均访问时间。
  • 命中率 H = 950 ÷ 1000 = 0.95
  • 平均访问时间 = 0.95 × 1 + 0.05 × (1 + 50) = 0.95 + 2.55 = 3.5 ns

4.3 虚拟存储器与 TLB

虚拟地址拆分 页内地址位数 = log₂(页面大小)
虚页号位数 = 虚拟地址位数 − 页内地址位数
TLB 地址拆分（组相联） TLB 组号位数 = log₂(TLB 组数)
TLB 标记位数 = 虚页号位数 − TLB 组号位数 TLB 用虚页号划分，不是物理地址
例题
虚拟地址 30 位，页大小 4KB，TLB 采用 2 路组相联共 8 组。求虚页号、TLB 标记、TLB 组号位数。
  • 页内地址 = log₂(4KB) = 12 位
  • 虚页号 = 30 − 12 = 18 位
  • TLB 组号 = log₂8 = 3 位
  • TLB 标记 = 18 − 3 = 15 位

4.4 存储器容量计算

存储区域容量 容量 = 末地址 − 首地址 + 1
例题
主存区域 600E1000H ~ 600FFFFFH，每单元 8 位，求容量。
  • 末地址 − 首地址 + 1 = 600FFFFFH − 600E1000H + 1 = 1F000H + 1 = 20000H
  • 20000H = 2¹⁷ = 128K × 8bit

计指令系统计算中频

5.1 扩展操作码

核心思想：短操作码不能再扩展时，留出一种编码用于扩展成更长的操作码，从而支持多种地址格式的指令。

例题
指令字长 16 位，地址码 4 位。若需 15 条三地址指令、15 条二地址指令、15 条一地址指令、16 条零地址指令，设计操作码。
  • 三地址：操作码 4 位，可表示 16 种，取 15 种（留 1 种扩展）
  • 二地址：用 1 种三地址操作码扩展出 2⁴ = 16 种，取 15 种（留 1 种扩展）
  • 一地址：用 1 种二地址操作码扩展出 2⁴ = 16 种，取 15 种（留 1 种扩展）
  • 零地址：用 1 种一地址操作码扩展出 2⁴ = 16 种，全部使用

5.2 寻址范围

例题
某机指令字长 16 位，地址码 6 位。若采用直接寻址，寻址范围？若采用间接寻址，寻址范围？
  • 直接寻址：2⁶ = 64 个单元
  • 间接寻址：地址码指向的单元中存放的是有效地址，若该单元也是 6 位，则 2⁶ = 64 个单元（需注意间接寻址的位数取决于存储字长）

计流水线计算高频

6.1 流水线周期

流水线时钟周期 Δt = max(各阶段时间) + 流水线寄存器延迟
例题
6 个子功能时间分别为 80ns、40ns、50ns、70ns、20ns、30ns，流水线寄存器延迟 20ns。合并 E 和 F 后，求时钟周期。
合并后各段为 80、40、50、70、50ns，最长 80ns，加寄存器延迟 20ns → 100 ns

6.2 吞吐率、加速比、效率

设 k 段流水线，每段 Δt，执行 n 条指令：

流水线总时间 Tk = (k + n − 1) × Δt
吞吐率 TP = n ÷ Tk
加速比 S = 非流水时间 ÷ 流水时间 = (k × n × Δt) ÷ Tk
效率 E = S ÷ k
例题
5 段流水线，每段 100ns，执行 20 条指令。求总时间、吞吐率、加速比、效率。
  • Tk = (5 + 20 − 1) × 100 = 2400 ns
  • TP = 20 ÷ 2400ns ≈ 8.33 × 10⁶ 条/s
  • S = (5 × 20 × 100) ÷ 2400 = 10000 ÷ 2400 ≈ 4.17
  • E = 4.17 ÷ 5 ≈ 83.4%

计总线与 I/O 计算中频

7.1 总线带宽

总线带宽 总线带宽 = 总线宽度（字节） × 总线频率 总线宽度是"位"，除以 8 才是字节
例题
总线宽度 32 位，频率 100MHz，求带宽。
32 位 = 4 字节，带宽 = 4 × 100M = 400 MB/s

7.2 DMA 传送时间

DMA 传送时间 DMA 传送时间 = 数据量 ÷ 传输速率 若按周期算：时间 = 字节数 × 每个字节占用周期数 × 总线周期
例题
DMA 每传送一个字节需 1 个总线周期，总线周期 200ns，传送 4KB 数据。求 DMA 占用总线时间。
4KB = 4096 字节，时间 = 4096 × 200ns = 819.2 μs
