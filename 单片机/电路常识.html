01

电的三个基本量

电压、电流、电阻 —— 一切电路分析的地基

在看懂任何电路之前，必须先建立三个量的直觉。用「水流」来类比电路，是最容易理解的方式。

电压 U — 电势差

电压是两点之间的电势差，单位是伏特（V）。它描述的是「电的推动力有多强」，就像水管两端的水压差。

  • 电池标称 1.5V、9V，就是这个电源能提供的电压差。
  • 单片机常用供电：5V（Arduino Uno）、3.3V（ESP32、STM32 多数型号）。
  • 电压是相对量，必须指明「两点之间」。所谓「某点电压 3.3V」，默认是以电路公共端（GND，即 0V）为参考。

电流 I — 电荷的定向移动

电流是单位时间内通过导体横截面的电荷量，单位是安培（A）。

1 A = 1000 mA = 1 000 000 μA
  • 单片机 GPIO 引脚驱动能力通常在 10~20 mA 量级，超过可能烧毁引脚。
  • 一颗普通 LED 的工作电流约 5~20 mA。
  • ESP32 工作时平均电流约 80~240 mA，WiFi 发射瞬时可达 500 mA。
◆ 电流方向约定

物理上电子从负极流向正极，但电路分析中我们统一采用「正电荷从高电位流向低电位」的方向，即从电源正极出发、经外电路回到负极。这是行业惯例，分析时不要纠结。

电阻 R — 对电流的阻碍

电阻表示导体对电流的阻碍作用，单位是欧姆（Ω）。

1 kΩ = 1000 Ω　　1 MΩ = 1 000 000 Ω

同样的电压下，电阻越大，电流越小。这就是欧姆定律要讲的内容。

02

欧姆定律

一个公式解决 80% 的入门计算
U = I × R　　I = U ÷ R　　R = U ÷ I U 单位伏特 V ｜ I 单位安培 A ｜ R 单位欧姆 Ω

例 1：已知电压和电阻，求电流

5V 电源接一个 100Ω 电阻，流过电阻的电流是多少？

I = U ÷ R = 5 V ÷ 100 Ω = 0.05 A = 50 mA

例 2：计算 LED 的限流电阻（最重要的应用）

用 3.3V 的 GPIO 驱动一颗红色 LED（正向压降 2.0V），希望电流为 10mA，需要多大电阻？

关键点：电阻两端的电压 = 电源电压 − LED 压降。

R = (3.3 V − 2.0 V) ÷ 0.01 A = 1.3 ÷ 0.01 = 130 Ω

130Ω 不是标准值，选最接近的标准电阻 150Ω。此时实际电流为 1.3 ÷ 150 ≈ 8.7 mA，仍在安全范围内，LED 亮度足够。

电功率 P

功率表示能量消耗的速率，单位瓦特（W）。电阻会把电能转化为热量，选电阻时必须校核功率。

P = U × I = I² × R = U² ÷ R

接上例：P = 1.3 V × 0.0087 A ≈ 0.011 W，远小于常见的 1/4W（0.25W）电阻额定功率，安全。

✓ 实用速记

单片机系统里，普通信号电阻统一选 1/4W 就够了，几乎不用计算功率。只有大电流场景（电机、加热、电源）才需要认真校核。

03

电阻

电路里出现频率最高的元件

3.1 电路符号

3.2 电阻的四大作用

作用说明典型场景
限流 限制流过元件的电流，防止烧毁 LED 串联电阻、三极管基极电阻
分压 把高电压按比例降为低电压 电池电压检测、电位器调压
上拉 / 下拉 给悬空引脚一个确定的默认电平 按键输入、I²C 总线
偏置 / 采样 设定工作点或把电流转换为电压 三极管放大、电流检测

3.3 色环读数

常见的四色环电阻，前两环是有效数字，第三环是倍率，第四环是误差。颜色对应数字：

黑 0　棕 1　红 2　橙 3　黄 4
绿 5　蓝 6　紫 7　灰 8　白 9
⚠ 读数要点

色环应从离端点最近的那一环开始读。金色和银色只出现在误差环，不可能作为第一环，可作为定位依据。

3.4 串联与并联

◆ 两个电阻并联的速算公式

R总 = (R1 × R2) ÷ (R1 + R2)

例：两个 10kΩ 并联 → (10000 × 10000) ÷ 20000 = 5 kΩ。相同阻值并联，结果就是阻值除以个数。

3.5 分压电路

两个电阻串联，从中间抽头取出的电压就是分压结果。这是单片机读取高于 ADC 量程的电压时最常用的技巧。

Vout = Vin × R2 ÷ (R1 + R2) 输出端接的是 R2 两端的电压

实例：用 3.3V 的 ADC 测量 12V 电池电压。选 R1 = 100kΩ，R2 = 10kΩ：

Vout = 12 × 10 ÷ (100 + 10) = 1.09 V

1.09V 落在 0~3.3V 量程内，安全。单片机读到 1.09V 后，程序中乘 11 即可还原出 12V。

⚠ 分压电路的负载效应

分压公式成立的前提是输出端几乎不取电流。如果 Vout 后面接了一个阻值不大的负载，等效于给 R2 并联了一个电阻，实际输出电压会偏低。所以分压后的信号一般只接到高阻抗的 ADC 输入端，不能直接驱动负载。

04

电容

储存电荷的元件，电源稳定的守护者

4.1 符号与单位

1 F = 1000 mF = 10⁶ μF = 10⁹ nF = 10¹² pF 法拉 F 是个极大的单位，实际电路中最常见 μF、nF、pF

4.2 核心特性：电压不能突变

电容储存的是电场能量，公式为 Q = C × U。它的两条铁律必须牢记：

  • 电容两端电压不能突变——电压要升高或降低，必须经过充电或放电过程。
  • 隔直通交——直流稳定后电容相当于断路；交流信号可以「通过」（反复充放电）。
时间常数 τ = R × C R 单位 Ω，C 单位 F，τ 单位秒

实例：R = 10 kΩ = 10000 Ω，C = 10 μF = 0.00001 F

τ = 10000 × 0.00001 = 0.1 s　　5τ = 0.5 s

也就是大约半秒后，电容基本充满。这就是为什么按键消抖电路里常用 10kΩ + 10μF 的组合。

4.3 电容在单片机电路里的典型用法

用途典型容值作用说明
电源去耦 0.1 μF 陶瓷电容 紧贴芯片 VCC 引脚放置，吸收瞬间电流波动，抑制高频噪声。每个电源引脚配一颗，这是硬性规范。
电源滤波 100 μF ~ 1000 μF 电解电容 放在电源入口，平滑整流后的纹波，应对大电流负载突变。
复位电路 0.1 μF ~ 10 μF 上电瞬间产生一个低电平脉冲，让单片机可靠复位。
信号耦合 1 μF ~ 10 μF 隔断直流分量，只让交流信号通过。
RC 滤波 / 消抖 0.01 μF ~ 10 μF 与电阻配合，滤除按键或信号线上的毛刺。
✓ 新手最容易忽略的一件事

在面包板上搭电路时，芯片的电源引脚旁边一定要接一颗 0.1μF 电容，并且引脚尽量短。很多「程序莫名其妙跑飞」「ADC 读数跳动」的问题，根源就是缺少去耦电容。

05

电感

储存磁场能量，与电容互为对偶

5.1 符号与单位

1 H = 1000 mH = 10⁶ μH 常见功率电感在 μH ~ mH 量级

5.2 核心特性：电流不能突变

电感储存的是磁场能量。它与电容恰好互补：

  • 电感中的电流不能突变——电流要变化，必须经过一个过程。
  • 通直阻交——直流稳定后电感相当于一根导线（只体现线圈电阻）；交流信号会受到阻碍。
  • 电流突变时会产生反向感应电动势，这就是为什么断开继电器或电机时会产生高压尖峰。
⚠ 实践中的关键点：续流二极管

用三极管或 MOSFET 驱动继电器、电机、电磁阀这类感性负载时，必须在负载两端反向并联一颗二极管（如 1N4148 / 1N4007）。断开瞬间线圈产生的反向高压会击穿驱动管。这是嵌入式硬件里最经典的保护电路。

5.3 电感的典型应用

应用说明
LC 滤波与电容组成 LC 低通滤波器，滤除电源或信号中的高频噪声
DC-DC 开关电源Buck 降压、Boost 升压电路的核心储能元件，效率可达 90% 以上
共模扼流圈USB、以太网接口上抑制共模干扰
无线充电 / 读卡线圈通过磁场耦合传递能量或数据（NFC、RFID）

5.4 三者对比速查

元件储存能量形式稳态直流特性不能突变的量单位
电阻 R不储能，直接发热导通，服从 U=IR—Ω
电容 C电场能相当于断路电压F
电感 L磁场能相当于导线电流H

记忆口诀：电容电压不突变，电感电流不突变。

06

LED 发光二极管

单片机学习中最先点亮的元件

6.1 符号与极性

LED 是二极管的一种，具有单向导电性：电流只能从阳极（A）流向阴极（K），反向不导通。接反了不亮，但一般不会损坏（除非反向电压过高）。

如何判断实物引脚

  • 看引脚长短：长脚是阳极（+），短脚是阴极（−）。
  • 看内部结构：从透明外壳看进去，电极片较大的那一侧是阴极（−）。
  • 看外壳缺口：有些 LED 外壳边缘有一个平切面，那一侧是阴极。
  • 万用表：调到二极管档，红表笔接阳极、黑表笔接阴极时 LED 会微弱发光。

6.2 正向压降与工作电流

LED 导通时两端有一个相对固定的压降，不同颜色差异很大，这是计算限流电阻的关键参数。

颜色正向压降 Vf典型工作电流常见用途
红色1.8 ~ 2.2 V5 ~ 20 mA电源指示、状态灯
黄色2.0 ~ 2.2 V5 ~ 20 mA状态指示
绿色2.2 ~ 3.2 V5 ~ 20 mA电源指示、通信指示
蓝色3.0 ~ 3.4 V5 ~ 20 mA高亮指示
白色3.0 ~ 3.4 V5 ~ 20 mA照明、背光
⚠ 3.3V 系统驱动蓝色 / 白色 LED 的坑

蓝色和白色 LED 的压降约 3.0~3.4V，而 3.3V 电源只比它高一点点。此时限流电阻必须取很小（甚至几十欧姆），电流对电压波动极其敏感，稍有偏差电流就急剧上升，很容易烧 LED 或拉低电源电压。建议用 5V 供电，或者用三极管 / MOSFET 驱动。

6.3 限流电阻计算完整流程

  1. 确定电源电压 UCC（如 5V）
  2. 查出 LED 正向压降 Vf（如红色取 2.0V）
  3. 确定期望电流 I（如 10mA = 0.01A）
  4. 代入公式
R = (UCC − Vf) ÷ I 5V 红色 LED，10mA：(5 − 2.0) ÷ 0.01 = 300 Ω → 取标准值 330 Ω
✓ 常用搭配速查表

5V + 红色 LED：330Ω 或 470Ω
5V + 绿色 / 蓝色 LED：220Ω 或 330Ω
3.3V + 红色 LED：150Ω 或 220Ω
3.3V + 绿色 LED：100Ω 或 150Ω

实际阻值大一点没关系，只是亮度略低；绝不能省略电阻。

07

按键与上下拉

单片机的输入通道，也是新手最容易踩坑的地方

7.1 按键的本质

轻触按键就是一个机械开关：不按时两端断开，按下时两端导通。它只有两个状态，正好对应数字逻辑的 0 和 1。

7.2 悬空问题：为什么必须加电阻

如果把按键一端接 GPIO、另一端接 GND，那么按键松开时 GPIO 是悬空的。悬空引脚的电压不确定，可能被周围电磁干扰耦合，读到的值随机跳动。

解决办法是给引脚一个确定的默认电平，这就要用上拉电阻或下拉电阻。

7.3 上拉接法

工作原理：松开时，电阻把 GPIO 拉到 VCC，读到高电平；按下时，GPIO 直接被短接到 GND，电阻上流过微小电流（3.3V ÷ 10kΩ = 0.33mA），GPIO 读到低电平。

◆ 上拉电阻为什么选 10kΩ

阻值太小：按键按下时白白消耗电流（1kΩ 时 3.3mA）。
阻值太大：抗干扰能力弱，容易受噪声影响，且上升沿变缓。
10kΩ 是功耗与抗干扰的最佳平衡点，是行业默认值。

7.4 下拉接法

✓ 实践中最常用的做法

大多数单片机（STM32、ESP32、Arduino）的 GPIO 内部都集成了可编程上拉电阻。所以实际接线时，按键一端接 GPIO、另一端接 GND，然后在代码里开启内部上拉即可，无需外部电阻。但外部上拉（10kΩ）抗干扰能力更强，长导线或工业环境下建议外置。

7.5 按键消抖

机械触点闭合的瞬间并不是干净的一次通断，而是会抖动 5~20ms，产生一串快速的高低电平跳变。如果程序直接读取，一次按下可能被识别成好几次。

消抖方案一：软件延时（最常用）

// 检测到电平变化后，等 20ms 再读一次，两次一致才算有效
if (digitalRead(BUTTON_PIN) == LOW) {
    delay(20);                     // 跳过抖动期
    if (digitalRead(BUTTON_PIN) == LOW) {  // 再次确认
        doSomething();
        while (digitalRead(BUTTON_PIN) == LOW); // 等待松开
    }
}

消抖方案二：硬件 RC 滤波

在按键两端并联一个 0.1μF 电容，或者在 GPIO 与按键之间串联 10kΩ 电阻 + 对地 0.1μF 电容。RC 时间常数约 1ms，可以把快速抖动平滑掉。

⚠ delay() 的代价

用 delay(20) 消抖会阻塞 CPU 20ms，期间什么都做不了。在简单程序里无所谓，但在多任务系统里应改用定时器扫描或状态机方式，每 5~10ms 采样一次按键状态并记录连续次数。

08

基尔霍夫定律

复杂电路的分析利器：KCL 与 KVL

欧姆定律只能解决单个元件的问题。当电路有多个分支、多个电源时，就需要基尔霍夫定律。

8.1 基尔霍夫电流定律 KCL

流入任一节点的电流之和，等于流出该节点的电流之和。本质是电荷守恒——电荷不会在节点堆积。

直观理解：就像水管三通，流进来的水量必然等于流出去的水量，不会凭空多出或消失。

8.2 基尔霍夫电压定律 KVL

沿任一闭合回路，各元件电压的代数和为零。本质是能量守恒——绕一圈回到原点，电势差必须归零。

沿回路：U − U1 − U2 − U3 = 0 10 − 3 − 3 − 4 = 0 ✓　电源升压 = 各电阻降压之和

8.3 用 KCL + KVL 解一个实际电路

问题：一个 5V 电源，串联 R1 = 1kΩ 后分成两条并联支路：R2 = 2kΩ 和 R3 = 3kΩ。求总电流和 R2 两端电压。

第一步：先算并联部分等效电阻

R并 = (2k × 3k) ÷ (2k + 3k) = 6k ÷ 5k = 1.2 kΩ

第二步：用 KVL 求总电流

回路总电阻 R总 = 1kΩ + 1.2kΩ = 2.2kΩ

I总 = 5 V ÷ 2200 Ω ≈ 2.27 mA

第三步：求 R2 两端电压

R1 上的压降：UR1 = 2.27mA × 1kΩ ≈ 2.27V

由 KVL，并联部分的电压 = 5V − 2.27V = 2.73 V。这就是 R2 和 R3 两端的电压。

第四步：用 KCL 验证

IR2 = 2.73 ÷ 2000 = 1.365 mA
IR3 = 2.73 ÷ 3000 = 0.910 mA
I总 = 1.365 + 0.910 = 2.275 mA ✓

与第二步计算的总电流一致，KCL 得到验证。

◆ 解题思路总结

1. 先化简电路结构（串并联合并）
2. 求总电阻、总电流
3. 用 KVL 逐段求电压
4. 用 KCL 验证分支电流
只要这四步走通，绝大多数基础电路都能解出来。

09

高低电平与数字逻辑

单片机只认识 0 和 1，但它面对的是连续电压

9.1 从模拟到数字

真实世界的电压是连续变化的，而数字电路只区分「高」和「低」两个状态。为了让芯片可靠识别，必须定义电压区间而不是一个精确值。

9.2 TTL 与 CMOS 电平标准

标准供电输入高电平 VIH输入低电平 VIL典型器件
5V TTL 5 V ≥ 2.0 V ≤ 0.8 V 74LS 系列、传统 51 单片机
5V CMOS 5 V ≥ 3.5 V（0.7×VCC） ≤ 1.5 V（0.3×VCC） CD4000 系列
3.3V CMOS 3.3 V ≥ 2.31 V（0.7×VCC） ≤ 0.99 V（0.3×VCC） STM32、ESP32、树莓派 Pico
⚠ 5V 与 3.3V 互连的经典陷阱

5V 输出 → 3.3V 输入：5V 直接灌进 3.3V 引脚，长期会损坏芯片。需要电平转换模块或电阻分压。
3.3V 输出 → 5V 输入：大多数情况可以工作（3.3V 高于 TTL 的 2.0V 门限），但接 CMOS 输入（门限 3.5V）就识别不了，需要电平转换。
安全做法：两端电压不一致时，一律加双向电平转换模块（如 TXS0108E）或用 MOS 管搭建转换电路。

9.3 三种 GPIO 输出模式

模式特点典型用途
推挽输出 内部上下两个 MOS 管，能主动输出高电平或拉低。驱动能力强，速度快。 驱动 LED、蜂鸣器、普通数字信号
开漏输出 只能主动拉低，输出高电平时呈高阻态，必须外接上拉电阻才能得到高电平。 I²C 总线（SDA/SCL）、多设备共享信号线
高阻输入 引脚不驱动任何电平，仅用于读取外部信号。 ADC 采样、按键输入
◆ 为什么 I²C 必须用开漏 + 上拉

I²C 总线上挂多个设备，任何一个设备都可以把总线拉低。如果用推挽输出，一个设备输出高、另一个输出低，就会形成短路大电流，烧毁引脚。开漏 + 上拉的方式让所有设备只能「拉低」或「放手」，天然避免了冲突。这就是「线与」逻辑。

记忆技巧：

  • 与：全 1 才为 1（串联开关，两个都闭合灯才亮）
  • 或：有 1 就为 1（并联开关，任一闭合灯就亮）
  • 非：取反
  • 异或：不同为 1，相同为 0（可用于奇偶校验、半加器求和位）

9.6 单片机中的位操作

理解了逻辑门，就能理解单片机代码中的位操作。这些操作在寄存器配置时无处不在：

// 置位：把第 3 位置 1（OR 逻辑）
reg |= (1 << 3);        // 0000 1000

// 清零：把第 3 位清 0（AND + 取反）
reg &= ~(1 << 3);       // 1111 0111

// 翻转：把第 3 位取反（XOR）
reg ^= (1 << 3);

// 读取：判断第 3 位是 0 还是 1
if (reg & (1 << 3)) { /* 该位为 1 */ }
✓ 为什么用位操作

单片机的一个寄存器通常 8 位或 32 位，每一位控制一个独立功能。直接赋值 reg = 0x08 会破坏其他位；用 reg |= (1<<3) 只改动目标位，这是嵌入式编程的基本素养。

电路图

参考代码（Arduino 语法）

const int LED_PIN    = 9;
const int BUTTON_PIN = 2;

void setup() {
    pinMode(LED_PIN, OUTPUT);
    pinMode(BUTTON_PIN, INPUT_PULLUP);  // 开启内部上拉，未按时为高电平
}

void loop() {
    if (digitalRead(BUTTON_PIN) == LOW) {   // 按下 = 低电平
        delay(20);                          // 软件消抖
        if (digitalRead(BUTTON_PIN) == LOW) {
            digitalWrite(LED_PIN, HIGH);      // 点亮 LED
            while (digitalRead(BUTTON_PIN) == LOW); // 等待松开
            digitalWrite(LED_PIN, LOW);
        }
    }
}
