单片机零成本学习指南
从入门到进阶，不买板子也能学

一份可以在浏览器里完成全部入门实践的路线图。你不需要在前期买任何开发板，所有实验都通过免费在线模拟平台完成。

1 学习路线：四阶段循序渐进
第 1–2 个月

基础铺垫期 · C语言 + 电路常识

  • C语言核心：语法结构、数据类型、函数、结构体、指针、位操作。指针和位操作是嵌入式开发中最高频的语法，务必重点掌握。[reference:0]
  • 电路常识：认识电阻、电容、电感、LED、按键；理解欧姆定律、基尔霍夫定律、高低电平与数字逻辑。[reference:1]
  • 工具：VS Code（轻量，适合长期使用）写C语言练习。
  • 目标：能独立写出带指针操作和结构体的C程序，看懂简单电路图。
第 2–3 个月

入门期 · 51单片机 · 裸机编程

  • 核心知识点：GPIO输入输出（流水灯、按键）、定时器、中断、串口通信（UART）、I2C、SPI。[reference:2]
  • 理解裸机编程：单片机的控制逻辑本质是电平信号操作，C语言底层仍然是寄存器读写。了解汇编语言有助于建立“寄存器思维”。[reference:3]
  • 开发工具：Keil C51（编译） + 在线模拟平台（运行验证）。
  • 目标：在模拟平台上完成流水灯、按键控制、定时器中断、串口收发等基础实验。
第 3–5 个月

进阶期 · STM32 · 标准工具链

  • 核心外设：GPIO、UART、SPI/I2C、ADC/DAC、DMA、定时器高级用法、中断优先级。[reference:4]
  • 工具链：STM32CubeMX（图形化配置） + Keil MDK-ARM 或 VS Code + STM32CubeIDE（开源免费）。学会用 SWD/J-Link 调试。[reference:5]
  • 数据结构补充：队列、栈、链表、环形缓冲区。这些结构在嵌入式通信和任务调度中大量使用。[reference:6]
  • 目标：能独立完成一个带多外设协同的小项目（如传感器采集 + 屏幕显示 + 串口上传）。
第 5–8 个月及以后

拓展期 · RTOS · 物联网 · Linux

  • RTOS：FreeRTOS 或 RT-Thread，掌握任务创建/调度、信号量、队列、定时器。[reference:7]
  • 物联网通信：WiFi、Bluetooth、LoRa 至少掌握一种，实现设备联网上传数据。[reference:8]
  • Linux 方向（可选）：Linux 基本操作、开发环境配置、驱动开发、应用开发。[reference:9]
  • 综合项目：在 STM32 上移植 FreeRTOS，多任务管理 + WiFi 联网上传温湿度数据到云端。[reference:10]
2 免费在线模拟平台：不买板子也能跑代码

Wokwi

最推荐 个人免费

目前最成熟的浏览器端嵌入式仿真平台，被 Espressif 官方列为 ESP32 推荐仿真工具，全球多所大学用于教学。打开网页就能拖出开发板、写代码、点运行，LED 直接亮起。[reference:11]

  • 支持芯片：Arduino Uno/Mega/Nano、ESP32 全系、STM32、树莓派 Pico、ATtiny85 等。[reference:12]
  • 支持语言：Arduino C++、MicroPython、CircuitPython、ESP-IDF、Rust。[reference:13]
  • 关键功能：WiFi 仿真（可连接真实互联网，跑 MQTT/HTTP）、虚拟逻辑分析仪（抓 UART/I2C/SPI 时序）、GDB 断点调试。[reference:14]
  • 免费限制：个人使用免费，项目为公开可见。商业/团队用途需要付费方案。[reference:15]
https://wokwi.com

Tinkercad Circuits

免费 国内可访问

Autodesk 出品的在线电路仿真工具，专注于 Arduino 仿真。界面极其简单，拖放元件、接线、写代码、一键运行，对纯新手最友好。[reference:16]

  • 支持 Arduino Uno R3 及常用传感器、LCD、舵机等。
  • 内置代码编辑器，支持 Arduino C++。
  • 实时仿真，接线错误会直观反馈。
https://www.tinkercad.com/circuits

Velxio

开源免费

开源多板卡模拟器，浏览器直接运行，无需安装。支持 40+ 开发板，覆盖 AVR、ARM Cortex-M（RP2040/STM32）等 CPU 家族。[reference:17]

  • 支持 Arduino Uno、ESP32、ESP32-C3、Raspberry Pi Pico、Raspberry Pi 3 等。[reference:18]
  • 核心开源（AGPLv3），可自托管。
  • 适合想深入了解仿真器工作原理的学习者。
https://velxio.dev/editor

EDSim51

免费

专门面向 8051 单片机的在线仿真器，如果你选择从 51 单片机入门，这个工具比通用平台更贴合学习场景。[reference:19]

  • 纯 51 指令集仿真，界面简洁。
  • 适合配合 51 单片机教材做课后实验。
https://edsim51.com
选择建议：如果你没有任何基础，从 Tinkercad Circuits 开始最轻松；想系统学习嵌入式开发，直接上 Wokwi，它对 Arduino / ESP32 / STM32 的支持最完整，且调试功能最强大。51 单片机学习者可以搭配 EDSim51 使用。
3 零成本学习流程：从第一个 LED 到完整项目

注册并创建第一个项目

打开 Wokwi 或 Tinkercad Circuits，创建一个新项目。Wokwi 无需安装任何软件，打开浏览器即可开始。[reference:20]

从“点亮一个 LED”开始

拖出一个开发板和一个 LED，接上限流电阻，写几行代码控制 GPIO 电平，点运行。这是所有单片机学习者的第一个实验，也是理解“代码控制硬件”最直观的入口。

逐步增加外设

在 LED 基础上依次加入按键（输入）、蜂鸣器（PWM）、LCD 屏幕（I2C/SPI）、传感器（ADC）。每一步只引入一个新概念，在模拟环境中随便接线、随便试错——不用担心烧板子。[reference:21]

用逻辑分析仪调试通信协议

Wokwi 内置虚拟逻辑分析仪，可以直接抓取 UART、I2C、SPI 的时序波形。学习通信协议时，这比看数据手册直观得多，也避免了购买示波器的开销。[reference:22]

完成一个综合小项目

例如：ESP32 + 温湿度传感器 + OLED 屏幕 + WiFi 上传数据到手机。Wokwi 支持 WiFi 仿真，可以在没有硬件的情况下把云端和协议全部调通。[reference:23]

此时再决定是否买板子

完成 2–3 个模拟项目后，你已经清楚自己需要什么芯片、什么外设。届时可以选择一块与实际项目匹配的开发板，把在模拟器里验证过的代码直接烧录进去。
