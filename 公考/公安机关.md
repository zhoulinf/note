

## 人民警察职业素养

人民警察素质：
+ 政治素质
+ 业务素质
+ 法律素质
+ 文化素质
+ 心理素质
+ 身体素质
高频考点： 对党、对人民绝对忠诚，是人民警察首要的政治品质

人民警察的职业道德特征：
+ 政治性
+ 法律性
+ 自觉性
+ 他律行
+ 示范性
+ 导向性
+ 职业性
人民警察职业道德三个最显著的特征：
+ **鲜明的阶级性**
+ **行为的表率性**
+ **鲜明的阶级性**

人名警察职业道德规范：
1. 忠诚可靠：听党指挥，热爱人民，忠于法律
2. 秉公执法：事实为据，秉持公正，惩恶扬善
3. 英勇善战：坚韧不拔，机智果敢，崇尚荣誉
4. 热诚服务：情系民生，服务社会，热情周到
5. 文明理性：理性平和，文明礼貌，诚信友善
6. 严守纪律：遵章守纪，保守秘密，诚信友善
7. 爱岗敬业：恪尽职守，勤学善思，精益求精
8. 甘于奉献：任劳任怨，顾全大局，献身使命
9. 清正廉洁：艰苦朴素，情趣健康，克己奉公
10. 团结协作：精诚合作，勇于担当，积极向上

**核心价值观**：**<em style="color: purple">忠诚、为民、公正、廉洁</em>**
+ 忠诚是人民警察的根本政治要求，是人民警察核心价值观的政治品格
+ 为民是核心价值观的根本宗旨，是根本出发点和落脚点
+ 公正是核心价值观的价值追求，公正是包括实体公正和程序公正
+ 廉洁是核心价值观的内在要求，也是思想基础

十六字方针： 对党忠诚（政治灵魂），服务人民（根本宗旨），执法公正（价值取向），纪律严明（重要保证）






## 人民警察纪律（2-3分)

1. 政治纪律
	+ 不得散步有损国家声誉、形象和威信的口头或书面言论
	+ 不得参加国家命令取缔、禁止以及未依法得到批准的社会团体或者其他组织
	+ 不得参加以反对国家目的的集会、游行、示威等活动
	+ 不得参加罢工
2. 组织纪律
	+ 坚持民主集中制原则
	+ 下级服从上级，个人服从组织，少数服从多数
	+ 不参与派性活动，听从组织调度，自觉接受监督，无条件地完成组织交办的工作
3. 工作纪律
	+ 包括履行公务、秉公执法、文明执法三个方面
4. 内务纪律（群众纪律）
	+ 要求在人民警察人事管理各个环节公开、公正、公平，保证唯才是举，任人唯贤；
	+ 对待人民群众文明礼貌，热情耐心，不推诿搪塞，不敷衍了事，不吃拿卡要，不谋取私利
5. 保密纪律





## 处分：

警告、记过、记大过、降级、撤职、开除



直接开除情形：
1. 逃往境外或者非法出境，违反规定滞留境外不归的
2. 参与、包庇或者纵容危害国家安全违法犯罪活动的
3. 参与、包庇或者纵容黑社会性质组织犯罪活动的
4. 私放他人出入境的
5. 向犯罪嫌疑人通风报信的
6. 以实施行政事业性收费、罚没的名义收取钱物不出具任何票据的
7. 吸食、注射毒品或者参与、组织、支持、容留卖淫、嫖娼、色情淫乱活动的
8. 携带枪支饮酒、酒后驾驶机动车，工作时间饮酒或者在公共场所酿酒滋事的造成严重后果的
9. 公安民警出租、出借所配备或者管理的公务用枪的
10. 公安民警违反公务用枪管理使用规定，构成犯罪的，依法追究刑事责任，并给予行政开除处分等



给予警告或者记过处分；情节较重的，基于记大过或者降级处分；情节严重的，给予撤职或者开除处分：【违规使用警用品、违规收钱的、违规办证的】

1. 违反警车管理使用规定或者违反规定使用警灯、警报器
2. 违反规定转借、赠送、出租、抵押、转卖警用车辆、警车号牌、警械、警服、警用标志和证件的
3. 违反规定使用警械的
4. 擅自设定收费项目、提供收费标准的
5. 违反规定设定罚款项目或者实施罚款的
6. 违反规定办理户口、身份证、驾驶证、特种行业许可证、护照、机动车行驶证和号牌等证件



其中4，5，6 情节严重最重可达撤职，不能达到开除情形

特殊记忆：
以下行为造成不良影响的，给予警告处分，情节严重的，给予记过处分，情节严重的，给予记大过处分
1. 在工作中对群众态度蛮横、行为粗暴、故意刁难或者吃拿卡要
2. 不安规定着装，严重损害任命警察形象的
3. 非因公务着警服进入营业性娱乐场所的
